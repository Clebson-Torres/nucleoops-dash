# NúcleoOps Dashboard

Frontend do NúcleoOps para operar agentes, jobs, artefatos e comandos permitidos.

## Desenvolvimento

```powershell
npm install
npm run dev
```

## Build

```powershell
npm run build
```

Configuração de autenticação (Supabase):
- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`
